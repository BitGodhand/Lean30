Lean30 PWA — fixed install package (Nov 8, 2026)

Upload the FIVE files index.html, manifest.webmanifest, service-worker.js, icon-192.png, and icon-512.png to the ROOT of your existing GitHub repository BitGodhand/Lean30. The README is optional. Upload directly, not the ZIP file.

Wait for GitHub Pages deployment, then on Android Chrome visit https://bitgodhand.github.io/Lean30/ and refresh once or twice. Chrome three-dot menu > Add to Home screen > Install. Select INSTALL, not Create shortcut.

If the old PWA cache persists, close the tab and reload it. Please back up existing Lean30 data before clearing browser storage. Data from the file:// version is not shared with the hosted version.

This is a PWA, not an APK. It is installed independently of the browser tab and opens in standalone mode; Android still uses Chrome technology to power it.
